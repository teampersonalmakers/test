# 가편집 작업실

이 폴더는 **파이널컷 자동 가편집의 유일한 창구**다. 사용자는 코딩을 하지 않는 유튜버이고, **모든 것을 여기 한 곳에서**
간단하게 하고 싶어 한다. 사용자가 "이건 어디서 말해야 하지?"를 고민하지 않게, 무슨 말이든 여기서 받아 알아서 처리한다.
말투는 쉬운 한국어, 개발 용어 금지, 보고는 짧게(한두 줄).

모든 실행은 `~/.local/share/fcp-autocut/bin/fcp ...` 형태 그대로 쓴다(확인창 없이 실행되도록 허용해 둔 형태).
원본 영상은 절대 수정·복사하지 않는다.

## 1. 영상을 받으면 → 가편집
- **영상 경로(여러 줄)나 폴더 경로를 붙여 넣으면** 따로 묻지 말고 바로 `fcp-autocut` 스킬 절차대로 시작한다.
  - 포맷을 말하지 않았으면 지난번 포맷(`fcp prefs`)으로 하고 한 줄로 알린다. 처음일 때만 묻는다.
  - 폴더면 폴더 경로를 그대로 넘기고 `--sort-time`(촬영 시각순).
- 시작할 때마다 `~/.local/share/fcp-autocut/편집취향.md`와 `fcp feedback summary`를 읽고 그 규칙대로 판단한다.
- 끝나면 파이널컷으로 바로 연다(`fcp open "<결과.fcpxml>"`).
- 영상을 **첨부(업로드)**하면 30MB 제한에 걸린다 → Finder에서 선택 → **Option+Command+C** → 붙여넣기 안내.

## 2. 사용자가 무슨 말을 하든 → 세 갈래로 스스로 분류해서 처리
사용자에게 분류를 묻지 않는다. 판단이 애매하면 (가)+(나)로 처리하고, 같은 문제가 다시 나오면 (다)로 올린다.

**(가) 이 영상만 고치기** — "12번 살려줘", "3분 20초쯤 잘린 말 살려줘", "c12 살려줘", "이것도 잘라줘"
→ 스킬의 "후속 요청 = 학습" 1단계로 고치고 build → 파이널컷 다시 열기 → `fcp feedback ... add`로 기록.

**(나) 내 취향** — "민지 리액션은 살려줘", "오프닝 인사는 짧게", "더 촘촘하게"
→ (가)처럼 고치고 + `편집취향.md`에 규칙으로 정리 + 숫자 조정이 필요하면 `my_presets.yaml`(한 번 묻고 동의 시).
→ "다음부터 ○○ 할게요" 한 줄로 알림.

**(다) 도구 자체의 문제** — 이런 신호면 도구를 직접 고친다:
- "또", "항상", "계속" 같은 말 / 여러 영상에서 같은 문제 / 취향이 아니라 **명백히 잘못된 동작**
  (예: 말이 아닌 소리를 살림, 반복을 못 알아봄, 순서가 뒤섞임, 오류로 멈춤)

도구 고치는 절차(매번 전부):
1. `fcp backup`으로 현재 도구를 보관한다(되돌리기용).
2. 원인을 실제로 찾는다: 이번 작업 폴더(`~/.local/share/fcp-autocut/projects/<제목>/`)의 `candidates.json`·`script.json`과
   `~/.claude/skills/fcp-autocut/scripts/` 코드를 읽고, **왜 그렇게 판단했는지** 확인한다. 추측으로 고치지 않는다.
3. 숫자만 바꾸면 되는 문제면 `my_presets.yaml`로 해결(코드 수정 X). 판단 로직 문제면
   `~/.claude/skills/fcp-autocut/scripts/`를 **최소한으로** 고친다.
4. 이번 문제를 재현하는 검사를 `~/.claude/skills/fcp-autocut/tests/test_my_fixes.py`에 추가한다
   (기존 검사의 `make_video`, `seg`, `W`, `proj` 사용법을 따라 할 것).
5. `fcp test` → **전부 통과할 때만** 반영. 하나라도 실패하면 고친 걸 되돌리고(backup에서 복사) 사용자에게
   "이 부분은 지금 안전하게 고치기 어려워서 일단 이 영상만 손으로 고쳤어요"라고 알린다.
6. 통과하면 `touch ~/.claude/skills/fcp-autocut/.local-modified`, 그리고
   `~/.local/share/fcp-autocut/도구변경기록.md`에 날짜·증상·원인·고친 내용·추가한 검사를 적는다.
7. 지금 영상을 다시 analyze → build → 파이널컷 열기. 사용자에게: "도구를 고쳤어요. ○○도 이제 자동으로 잘려요." 한 줄.

지켜야 할 원칙(도구를 고쳐도 절대 바꾸지 않음): 원본 영상 읽기만 / 결과는 FCPXML+리포트만 / 확신 없는 삭제는 마커 /
받아쓰기 모델은 동의 없이 받지 않음 / 수치는 presets·my_presets에만.

## 3. 그 밖의 말
- **유튜브 링크** → 스킬의 "유튜브 영상으로 배우기".
- "좋아", "완료" → 끝. 칭찬도 `--kind other`로 기록(무엇이 잘 맞았는지 남김).
- "보관해 둔 수정 다시 적용해줘" → `~/.local/share/fcp-autocut/backup/`의 최근 `before-reinstall-*`과 현재 도구를 비교해
  `도구변경기록.md`에 적힌 수정들을 새 버전에 다시 적용(위 '도구 고치는 절차' 4~6 동일).
