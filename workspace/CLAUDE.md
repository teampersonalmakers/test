# 가편집 작업실

이 폴더는 **파이널컷 자동 가편집 전용**이다. 사용자는 코딩을 하지 않는 유튜버이고, 최대한 간단하게 쓰고 싶어 한다.
말투는 쉬운 한국어, 개발 용어 금지, 보고는 짧게.

## 사용자가 이렇게 하면
- **영상 경로(하나 또는 여러 줄)나 폴더 경로를 붙여 넣으면** → 따로 묻지 말고 바로 `fcp-autocut` 스킬 절차대로
  가편집을 시작한다("컷편집해줘"라는 말이 없어도).
  - 포맷을 말하지 않았으면 지난번 포맷(`~/.local/share/fcp-autocut/bin/fcp prefs`)으로 진행하고 한 줄로 알린다.
    처음이라 기록이 없을 때만 묻는다.
  - 폴더 경로면 `~/.local/share/fcp-autocut/bin/fcp videos "<폴더>"`로 영상만 골라 이름순으로 쓴다.
- **끝나면 파이널컷으로 바로 연다** (`~/.local/share/fcp-autocut/bin/fcp open "<결과.fcpxml>"`).
- **같은 대화에서 피드백**("12번 살려줘", "3분 20초쯤 잘린 말 살려줘", "더 촘촘하게", "민지 리액션은 살려줘")을 하면
  받아쓰기 없이 고쳐서 다시 만들고 파이널컷으로 다시 연다. 결과 타임라인 시각으로 말하면 리포트의 "결과 ○○ 부근"으로 번호를 찾는다.

## 흐름: 영상 → 가편집 → 파이널컷 → 피드백 → 적립 → 더 정교하게
1. 시작할 때마다 `~/.local/share/fcp-autocut/편집취향.md`와 `~/.local/share/fcp-autocut/bin/fcp feedback summary`를
   읽고 그 규칙대로 판단한다(이게 "내 스타일"이다).
2. 피드백을 받으면 스킬의 "후속 요청 = 학습" 3단계(고치기 → `fcp feedback ... add`로 기록 → 편집취향.md에 규칙 정리)를
   **매번 빠짐없이** 한다. 사용자에게는 "다음부터 ○○는 남길게요"처럼 한 줄로만 알린다.
3. 같은 종류 피드백이 쌓여 설정 조정 제안이 나오면 한 번 묻고, 동의하면 `my_presets.yaml` 등 '내 설정'에 반영한다.
4. 피드백이 없으면("좋아", "완료") 그대로 끝낸다. 칭찬도 `--kind other`로 기록해 두면 무엇이 잘 맞았는지 남는다.
- **유튜브 링크를 주면** 스킬의 "유튜브 영상으로 배우기" 절차를 따른다.

## 주의
- 영상을 **첨부(업로드)하면 30MB 제한**에 걸린다. 업로드는 필요 없으니 Finder에서 영상 선택 →
  **Option+Command+C** → 여기 붙여넣기를 안내한다.
- 모든 실행은 `~/.local/share/fcp-autocut/bin/fcp ...` 형태 그대로 쓴다(확인창 없이 실행되도록 허용해 둔 형태).
- 원본 영상은 절대 수정·복사하지 않는다.
